# Notice

## Repository purpose

This repository is a portfolio case study documenting the modernization of the legacy STRADA scientific application from Python 2 to Python 3.

It is intended to demonstrate software modernization, compatibility work, validation methodology, packaging, and engineering decisions carried out during the project.

## Original software

The historical STRADA application identifies the original project with:

Politecnico di Torino
Programma di Cooperazione Transfrontaliera Italia-Svizzera 2007-2013

All rights relating to the original STRADA software and its original materials remain with their respective rights holders.

## Repository scope

This public case-study repository does not contain:

- the original STRADA source code;
- the complete derived application source code;
- original scientific datasets;
- executable binaries;
- installer packages.

Code examples included in this repository, if any, are independently written examples created to illustrate modernization techniques and are not intended to reproduce the original application source code.

## Independence

STRADA Renaissance is an independent modernization and portfolio project. No affiliation with or endorsement by Politecnico di Torino or the original project institutions is implied.
